# Фрагменты исходного кода

Здесь лежит небольшая часть SYB - чтобы было видно, как устроены ключевые вещи. Полный проект не публикуется.

| Файл | Что внутри |
|---|---|
| [`sybcore/instance.go`](sybcore/instance.go) | Жизненный цикл ядра SYBcore: проверка конфигурации, запуск Xray и TUN, корректная остановка |
| [`sybcore/dialer.go`](sybcore/dialer.go) | Защита исходящих сокетов: трафик ядра не попадает обратно в туннель, при ошибке соединение закрывается |
| [`sybcore/platform.go`](sybcore/platform.go) | Мост между ядром на Go и Android |
| [`android/NetworkMeasurement.kt`](android/NetworkMeasurement.kt) | Замер задержки: SYBping, TCP, DNS, ICMP и HTTP через туннель |
| [`android/AppVersion.kt`](android/AppVersion.kt) | Схема версий: `1.0.4-beta.N` всегда старше `1.0.3` и младше `1.0.4` |

## SYBping

1. Адрес сервера определяется один раз - DNS не входит в результат.
2. Выполняются четыре TCP-рукопожатия подряд.
3. Первое отбрасывается: оно прогревает маршрут и почти всегда медленнее.
4. Итог - медиана остальных. Неудачные попытки не подменяются нулём.

Так значение не скачет от разового всплеска и честно показывает задержку до сервера.
